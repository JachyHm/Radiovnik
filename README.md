# Radiovník
Simple offline utility for traindrivers containing basic infrastructure radio information.

Current live version available at [simp.jachyhm.cz](https://simp.jachyhm.cz).

Jednoduchá offline aplikace pro strojvedoucí, obsahující základní informace o rádiovém spojení na zaměstnance řídící provoz.

Aktuální verze dostupná na adrese [simp.jachyhm.cz](https://simp.jachyhm.cz).
